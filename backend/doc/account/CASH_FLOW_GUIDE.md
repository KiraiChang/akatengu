# Cash Flow Category 分類指南

本文件說明 `accounts.cash_flow_category` 欄位的分類原則，以及 seed 資料中各科目的歸屬原因。

---

## 概述

### 欄位定義

`cash_flow_category` 是 `accounts` 資料表的可選欄位，允許值：

| 值 | 說明 |
|----|------|
| `CASH` | 現金及約當現金科目，用於計算現金流量表的**期初現金**與**期末現金** |
| `OPERATING` | 營業活動調整項目 |
| `INVESTING` | 投資活動調整項目 |
| `FINANCING` | 籌資活動調整項目 |
| `NULL` | 不參與現金流量表計算（彙總節點、損益類、已結轉的權益科目） |

### 報表關聯

現金流量表（`GET /report/cash_flow_statement`）以**間接法**編製：

1. **期初現金**：查詢 `CASH` 科目在 `start_date`（不含）之前的累計借貸差額
2. **淨利**：呼叫 `GetIncomeStatement` 取得本期損益
3. **三大活動調整**：對 `OPERATING`、`INVESTING`、`FINANCING` 各科目計算 `期間 credit − 期間 debit`
4. **期末現金**：查詢 `CASH` 科目在 `end_date`（含）當日為止的累計借貸差額

### 間接法公式

> 現金流量影響 = `期間 credit − 期間 debit`

此公式適用於所有非 CASH 科目，無需依科目類型分支：

- **資產科目**（借方正常）：資產增加 → debit > credit → 結果為負 → 現金流出 ✓
- **負債科目**（貸方正常）：負債增加 → credit > debit → 結果為正 → 現金流入 ✓
- **權益科目**（貸方正常）：資本增加 → credit > debit → 結果為正 → 籌資流入 ✓

## CASH — 現金及約當現金

現金科目代表「手上的錢」，作為現金流量表的期初與期末基準。

| 科目代號 | 科目名稱 | 說明 |
|---------|---------|------|
| 1101-01 | 手頭現金 | 皮夾、收銀機等實體現鈔 |
| 1101-02 | 銀行活期存款 | 可隨時提領的活期帳戶 |
| 1101-03 | 銀行定期存款（3個月內到期） | 到期日在3個月以內，視同約當現金 |
| 1101-04 | 電子支付餘額 | LINE Pay、街口、玉山Pi等儲值餘額 |

> **注意**：定期存款超過3個月到期者應歸入 INVESTING，而非 CASH。

## OPERATING — 營業活動

| 1103-09 | 其他應收款 | 未分類的流動應收項目，屬一般營業往來 |

## 不設分類（NULL）

以下類型的科目**刻意不設定** `cash_flow_category`，不參與現金流量表調整項目計算：

### 彙總節點（is_summary = TRUE）

所有中間彙總節點（如 `110 流動資產`、`210 流動負債`、`310 個人淨資產`）均為 `NULL`。

**原因**：彙總節點不直接對應任何交易分錄，journal_entries 只記錄到葉節點。若對彙總節點設分類，反而會造成重複計算（子科目已各自計算過）。

### 損益類科目（INCOME / EXPENSE）

所有收入科目（4xx）與費用科目（5xx）均為 `NULL`。

**原因**：間接法以「淨利」為起點，損益科目的影響已整體反映在 `GetIncomeStatement` 的 `NetIncome` 中。若再對個別損益科目加入調整，將造成重複計算。

### 結轉型權益科目

| 科目代號 | 科目名稱 | 說明 |
|---------|---------|------|
| 3101-01 | 期初結餘 | 每年度關帳時結轉上期損益，屬帳務結轉，非現金流動 |
| 3102-01 | 本年度淨利 | 損益表結果科目，已透過 NetIncome 虛擬行呈現 |
| 3102-02 | 本年度淨損 | 同上 |
| 3102-03 | 其他綜合損益 | 評價調整，非現金 |
| 3102-11 | 本月淨利 | 月結快照結果，帳務用途 |
| 3102-12 | 本月淨損 | 同上 |
| 3102-13 | 本季淨利 | 同上 |
| 3102-14 | 本季淨損 | 同上 |

### 其他未分類負債

| 科目代號 | 科目名稱 | 說明 |
|---------|---------|------|
| 2203-09 | 其他長期負債 | 性質未明確，暫不分類，待確認後可補設 |

## 新增科目的分類原則

當使用者新增科目時，應參考以下決策流程：

```
科目是否代表「手上的現金或3個月內到期的流動資產」？
  → 是 → CASH

科目是否與長期資產購置、金融投資買賣有關？
  → 是 → INVESTING

科目是否與借款取得、還款、個人資本存提有關？
  → 是 → FINANCING

科目是否為損益類（INCOME/EXPENSE）或彙總節點？
  → 是 → NULL（不設分類）

其餘（應收款、應付款、預付款、預收款、遞延稅等日常營業）
  → OPERATING
```

> **重要**：若科目未設定 `cash_flow_category`，該科目的期間變動將**靜默略過**，不出現在現金流量表任何分類中。這對彙總節點和損益類是預期行為，但對實際發生交易的葉節點可能導致報表數字不完整。
